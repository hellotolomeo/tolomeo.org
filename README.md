# tolomeo.org — build kit

Starter kit for building the site with Claude Code. Drop the contents of this folder into the
root of the repository, commit, then start a Claude Code session on the repo with:

> Read BRIEF.md and build the site.

What's here:

- `BRIEF.md` — the full spec (v2). `BUILD-PLAN-RESPONSE.md` — decisions on the builder's plan. `CLAUDE.md` — standing rules Claude Code loads every session.
- `design/` — approved artboards as HTML plus reference screenshots (see `design/README.md`).
- `fonts/` — Fluxisch Else Light and Bold.
- `content/` — 31 projects and the site text, ready to build from.
- `scripts/import-projects.py` — spreadsheet → project files.
